# Чороон XXI Век — сайт

Интернет-магазин и сайт торгово-производственной компании «Чороон XXI Век» (Якутск, с 2001 года): якутская национальная посуда и сувениры из фарфора и керамики.

Статический сайт без сборки: HTML + CSS + JS.

## Страницы
- `index.html` — магазин: каталог, корзина и оформление заказа, мастер-классы, контакты
- `about.html` — история компании, таймлайн 2001 → сегодня
- `news.html` — архив новостей
- `policy.html` — политика конфиденциальности

## Где что лежит
- `data/products.js` — каталог (сейчас заглушки, **цены ориентировочные**)
- `data/history.js` — таймлайн, `data/news.js` — новости
- `js/app.js` — вся логика; куда уходят заказы — `CONFIG.endpoint` в начале файла (пока пусто: покупатель передаёт заказ менеджеру письмом, звонком или через ВКонтакте)
- `css/styles.css`, `fonts/` (Dela Gothic One — заголовки, Geologica — текст), `img/`

## Запуск локально
```
python3 tools/serve.py 8420
```
и открыть http://localhost:8420/

После правок шапки или подвала в `index.html` пересобрать остальные страницы: `python3 tools/build.py`.
